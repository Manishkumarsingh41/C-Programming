## 🚀 How to Run the Code

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Manishkumarsingh41/C-Programming.git
   cd C-Programming
   ```

2. **Compile and Run Any File**
   ```bash
   gcc filename.c -o output
   ./output
   ```
